# DSCI 552 Homework 4

## Structure

- `notebook/Zuo_Xiyi_HW4.ipynb`: completed, executed homework notebook
- `data/AReM/`: Activity Recognition system based on Multisensor data fusion
- `requirements.txt`: Python dependencies

## Run

```bash
python -m pip install -r requirements.txt
cd notebook
jupyter notebook Zuo_Xiyi_HW4.ipynb
```

The notebook reads the data with the relative path `../data/AReM`. Run it from the `notebook` directory.
