# DSCI 552 Homework 7

## Structure

- `notebook/Zuo_Xiyi_HW7.ipynb`: completed, executed homework notebook
- `data/Frogs_MFCCs.csv`: Anuran Calls (MFCCs) data set
- `requirements.txt`: Python dependencies

## Run

```bash
python -m pip install -r requirements.txt
cd notebook
jupyter notebook Zuo_Xiyi_HW7.ipynb
```

The notebook reads the data with the relative path `../data/Frogs_MFCCs.csv`. Run it from the `notebook` directory.
