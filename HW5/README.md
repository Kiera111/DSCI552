# DSCI 552 Homework 5

## Structure

- `notebook/Zuo_Xiyi_HW5.ipynb`: completed, executed homework notebook
- `data/diagnosis.data`: Acute Inflammations data (UCI)
- `data/communities.data`: Communities and Crime data (UCI)
- `requirements.txt`: Python dependencies

## Run

```bash
python -m pip install -r requirements.txt
cd notebook
jupyter notebook Zuo_Xiyi_HW5.ipynb
```

The notebook reads the data with the relative paths `../data/diagnosis.data` and `../data/communities.data`. Run it from the `notebook` directory.
